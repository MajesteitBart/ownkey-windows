# Ownkey for Windows v0.5.0

Ownkey now brings fast, multilingual dictation to your own PC. The new
Local (Orukeet) option runs on your CPU, with no dedicated graphics card
required. Download the model once, then transcribe offline with no API key or
per-minute transcription fees. Your audio stays on your PC.

On our Intel Core i5-13600KF test PC, 6-7 seconds of synthetic English or Dutch
speech took **less than half a second to transcribe** once the model was loaded.
Longer 37-41-second clips took about **2-4 seconds**. These are CPU decoding
times; loading, recording, rewriting, and text insertion are separate.

## Local transcription with Orukeet

- [Orukeet by Oruk AI](https://huggingface.co/oruk/orukeet) builds on NVIDIA's
  Parakeet TDT 0.6B v3 speech model. It recognises 25 European languages,
  including Dutch and English, with automatic language detection, punctuation,
  and capitalisation.
- Add names and specialist terms to your dictionary to guide recognition.
  Filler words are removed locally without a language model.
- Choose **Settings > Transcription > Local (Orukeet)**, download the model,
  wait for **Installed · Not active**, and click **Save**. The installer includes
  the local runtime, so no Python or CUDA installation is needed.
- The model unloads after a configurable idle period and reloads on the next
  dictation. Loading took about two seconds on our test PC. Set the idle timeout
  to zero to keep the model in memory.
- Rewriting uses the provider you select and can send the transcript to a cloud
  service. For fully offline dictation, turn rewriting off or use local Ollama.

## What you need for local transcription

| Resource | Requirement or guidance |
|---|---|
| Windows | Windows 10 or 11 on a 64-bit Intel or AMD PC, plus a microphone |
| Processor | Runs on the CPU; no dedicated GPU required. Timings above were measured on an Intel Core i5-13600KF using four CPU threads. |
| Memory | Budget **2 GB of available RAM** for short dictation, in addition to Windows and your other apps. The test process peaked at about 1.3 GB. Longer recordings can need more. |
| Download | One-time **487 MB** model download; internet is needed for setup, then local transcription works offline. |
| Storage | Allow **1.3 GB free** for model download and extraction, in addition to the app. The installed model occupies **672 MB**. |

The memory budget is practical guidance, not a tested minimum. Measurements
come from one Windows 11 desktop with 64 GB RAM and synthetic speech; speed
varies with hardware, recording length, and other running apps. Cloud
transcription remains available if you prefer it.

## Dictionary

- Settings > Dictionary holds words and corrections. Words are passed to the
  recognizer as hints: Orukeet hotwords, Mistral context bias, the prompt field
  for OpenAI-compatible endpoints, and instruction text for Gemini.
- Corrections replace a misspelling with the spelling you want, whole word and
  case-insensitive, after transcription and before any AI rewrite. They work
  with every provider.

## Filler words

- Hesitations such as "uh", "um" and "ehm" are removed by rules, so nothing is
  sent to a language model and no latency is added. English and Dutch are on by
  default; German, French, and Spanish can be enabled.
- Words that carry meaning in another enabled language stay: "er" when Dutch is
  on, "um" when German is on.
- A removed sentence-opening filler capitalises the next word, line breaks are
  kept, and names such as iPhone keep their casing. Personal tics can be added
  as extra words.

## Redesigned settings

- Sidebar navigation with five pages: Dictation, Transcription, Dictionary,
  Filler words, and Rewriting.
- Ownkey brand styling with the bundled Bricolage Grotesque typeface, pill
  buttons, toggles, and cards. The window is still tkinter, so there is no new
  process.

## Linux (experimental)

- Source-based support for Ubuntu GNOME on Wayland: microphone capture,
  hold-to-talk keys through evdev, Unicode paste through wl-clipboard, and the
  Tauri overlay positioned through XWayland. There is no Linux installer yet.

## Configuration

Existing configuration files are retained. New keys:
`local_model_directory`, `local_model_idle_timeout_minutes`, `vocabulary`,
`corrections`, `remove_fillers`, `filler_languages`, and `custom_fillers`.
Filler removal starts enabled for English and Dutch with empty dictionaries.
The idle timeout defaults to 20 minutes.

## Release packaging

A public Windows installer must pass the signing verifier described in
[Windows release signing](../WINDOWS_RELEASE_SIGNING.md). An unsigned development
installer is not a release-qualified asset.
